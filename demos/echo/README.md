# Echo demo

The hello world of events: send an event to a pico and get back the directive a rule answers with.

- Overview: [`docs/cookbook/echo/README.md`](../../docs/cookbook/echo/README.md) (on the docs site: https://docs.picolabs.io/#/cookbook/echo/)
- Instructions: [`docs/cookbook/echo/instructions.md`](../../docs/cookbook/echo/instructions.md)

| File | Shows |
|------|-------|
| `com.example.echo.krl` | Two rules that answer `echo:hello` and `echo:message` with a `say` directive, and a page that sends both |
| `com.example.echo.bootstrap.krl` | Sets up the demo on a new pico; the **Try It!** tab runs it |
