# Compound Events

Compound event expressions allow you to combine primitive events to form event scenarios. Event expressions provide a robust, precise notation for expressing complex patterns on event streams. Complex event expressions are not new; they have been the subject of research in database trigger languages since the 1990s and have been used since then in event engines in a variety of disciplines. What *is* new is their application to real-time data streams on the Web.
