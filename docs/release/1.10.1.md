# Pico Engine 1.10.1 — release notes

**Status:** November 17, 2026

Patch on [1.10.0](1.10.0.md). Package versions are 1.10.1. In-repo dependency ranges stay `^1.10.0`.

## Fix

Startup compiles each ruleset cache file once. The JavaScript is written to a temporary file in the same directory and renamed into place. Every other pico waits for that compile instead of writing the same path.

1.10.0 recompiled every stored ruleset because the cache directory includes the compiler version. Many picos wrote the same file at once, and a load of the half-written module deleted it. Startup then logged `Compiled ruleset is missing init` for rulesets such as `io.picolabs.pds`.

## Upgrade

Install `pico-engine@1.10.1`. The first boot fills a new cache directory and is slower than a later restart.

Run one engine on a given `PICO_ENGINE_HOME`. This wait is inside one process. Two engines on the same directory can still compile the same file at once.
