## Before release day (prep)

### 1. Confirm `pico-framework` on npm

Engine depends on **`pico-framework ^0.8.2`**. Publish framework **before** engine if needed.

```sh
npm view pico-framework version
# Expect 0.8.2

cd /Users/pjw/Dropbox/prog/picolabs/pico-framework
npm run build
npm publish   # only if 0.8.2 is not on npm yet
```

### 2. Land pico-engine on a release branch

Merge or finish feature work (e.g. `cursor/root-build-includes-ui` → `main` or `release/1.8.0`).

```sh
cd /Users/pjw/Dropbox/prog/picolabs/pico-engine
git status
```

### 3. Bump versions (engine monorepo)

Update **`lerna.json`** `"version"` and every **publishable** `packages/*/package.json`:

- **Not published:** repo root (`private: true`), `packages/pico-engine-ui` (`private: true`).
- **Typical 1.8 bump:**

| Package | Was | Target |
|---------|-----|--------|
| `pico-engine`, `pico-engine-core`, `pico-engine-ui` | — | **1.8.0** ✓ |
| `krl-parser`, `krl-compiler`, `krl-generator`, `krl-stdlib` | — | **1.6.0** ✓ |

Align **`pico-engine`** dependencies on KRL packages to **`^1.6.0`** (or whatever you bump to).

### 4. Finalize release notes

- Ship **`docs/release/1.8.0.md`** (draft → final).
- If docs changed: `node tools/generate-llms-text.js` from repo root.

### 5. Commit companion repos

Manifold and sensor can be tagged **after** engine is on npm/Docker, but KRL commits should be ready on `main`.

## pico-engine **1.8.0**

### A. Build and test (gate)

```sh
cd /Users/pjw/Dropbox/prog/picolabs/pico-engine   # repo root — not packages/pico-engine
npm run setup    # npm i + lerna bootstrap
npm run build
npm test
npm run test:schema
npm run test:agent
cd packages/pico-engine && npm run test:policy && npm run test:mcp && npm run test:layer2-policy
cd ../..
```

Fix anything red before publish.

### B. Publish npm (maintainer)

```sh
cd /Users/pjw/Dropbox/prog/picolabs/pico-engine
npm whoami
npm run publish   # npm run build && lerna publish from-package --yes
```

Do **not** rely on publishing the repo root or `pico-engine-ui` (both private).

### C. Git tag + GitHub release

```sh
cd /Users/pjw/Dropbox/prog/picolabs/pico-engine
git tag -a v1.8.0 -m "Pico Engine 1.8.0"
git push origin main          # or your release branch
git push origin v1.8.0        # tags are NOT pushed with a normal push
gh release create v1.8.0 --title "1.8.0" --notes-file docs/release/1.8.0.md
```

### D. Docker image (Manifold + sensor harnesses)

```sh
cd /Users/pjw/Dropbox/prog/picolabs/pico-engine
docker build -f Dockerfile.local \
  --build-context pico-framework=../pico-framework \
  -t picolabs/pico-engine:1.8.0 \
  -t picolabs/pico-engine:latest .

docker run --rm picolabs/pico-engine:1.8.0 node -e \
  "console.log(require('./packages/pico-engine/package.json').version)"

# Push to your registry, e.g.:
# docker push picolabs/pico-engine:1.8.0
# docker push picolabs/pico-engine:latest
```

### E. Smoke test published engine

```sh
npm install -g pico-engine@1.8.0
PICO_ENGINE_HOME=/tmp/pico-18-smoke pico-engine &
curl -s http://localhost:3000/api/dev/local | jq .
# stop engine when done
```
