## Scope

### 1. did:peer:4 (new relationships)

| Item | Notes |
|------|--------|
| **Library** | Vendor or wrap [DIF did-peer-4](https://github.com/decentralized-identity/did-peer-4) — `@veramo/did-provider-peer` v7 supports numalgo **0/2 only** |
| **Creation** | `createPeerDidWithKeys()` in `veramoDidComm.ts` — today hard-coded `num_algo: 2` |
| **Interop** | **No auto-convert** peer:2 → peer:4; existing layer2 subs keep working |
| **Matching** | Extend `peerDidMatches()` in `store.ts` for numalgo 4 short/long forms |
| **Tests** | Update `epic9Matrix.ts` (`did:peer uses num_algo 2` → peer:4 for new subs); keep peer:2 regression |

**Design:** [`pico-identity-libraries.md`](../design/pico-identity-libraries.md) · [`sky-didcomm-protocol.md`](../design/sky-didcomm-protocol.md)
