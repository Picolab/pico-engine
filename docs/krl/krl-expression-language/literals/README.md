# Literals

The following literals can be used within KRL.

- [Booleans](/krl/krl-expression-language/literals/booleans)
- [Numbers](/krl/krl-expression-language/literals/numbers)
- [Hex](/krl/krl-expression-language/literals/hex)
- [Strings](/krl/krl-expression-language/literals/strings)
- [Regular Expressions](/krl/krl-expression-language/literals/regular-expressions)
- [Arrays](/krl/krl-expression-language/literals/arrays)
- [Maps](/krl/krl-expression-language/literals/maps)
- [Extended Quoting](/krl/krl-expression-language/literals/extended-quoting)
- [Beestings](/krl/krl-expression-language/literals/beestings)

Many literals can be cast (or coerced) into another type using the [`as()` operator](http://picolabs.atlassian.net/wiki/spaces/docs/pages/1189580/Universal+Operators#UniversalOperators-as()).
