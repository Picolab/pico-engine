# Numbers

KRL supports integer and real values. A negative number is created by prepending the minus sign (`-`) to a number in the usual fashion. KRL does not support exponential (scientific) notation.

Strings that represent numbers can be cast (coerced) to a number using the [`as()` operator](http://picolabs.atlassian.net/wiki/spaces/docs/pages/1189580/Universal+Operators#UniversalOperators-as()).
