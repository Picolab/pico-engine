# Pico Engine 1.10.2 — release notes

**Status:** November 23, 2026

Patch on [1.10.1](1.10.1.md). Package versions are 1.10.2. In-repo dependency ranges stay `^1.10.0`.

## Security

MCP tool arguments built from a pico schema cap arrays at 1000 elements. `zod` is `^4.6.7`. That release rejects an oversized array before it reads the elements, which closes GHSA-mrhx-c7xc-m3w5 (Dependabot #21). On 1.10.1 the dependency was `zod` `^3.25.76`, and `mcp/schemaToZod.js` built `z.array(z.any())` with no bound. A size check on that older Zod still walked every element.

Map and object attributes use Zod 4's two-argument record form. A normal object value is unchanged. Channel tags passed as an array have the same 1000-element cap.

## Upgrade

Install `pico-engine@1.10.2`, or pull [`public.ecr.aws/f0m0d1a1/pico-engine:1.10.2`](https://gallery.ecr.aws/f0m0d1a1/pico-engine) (`latest` is the same image, Linux ARM64).

An array attribute longer than 1000 elements is refused by the MCP tool. Shorter arguments are unchanged. URL-encoded request bodies are still accepted up to 512 MB.
