# Pico views demos

Rulesets that serve XMLUI pages from a pico. The engine's view tests also use them.

- Overview: [`docs/cookbook/xmlui/README.md`](../../docs/cookbook/xmlui/README.md) (on the docs site: https://docs.picolabs.io/#/cookbook/xmlui/)
- Instructions: [`docs/cookbook/xmlui/instructions.md`](../../docs/cookbook/xmlui/instructions.md)

| File | Shows |
|------|-------|
| `com.example.hello.krl` | A `@view` and nothing else |
| `com.example.fav_color.krl` | A query and an event |
| `com.example.guestbook.krl` | An app channel created on install |
| `com.example.contacts.krl` | A list page and a detail page |
| `com.example.thermostat.krl` | Two channels, an app `@component`, and the shared components |
| `com.example.thermostat.bootstrap.krl` | Sets up the Thermostat demo on a new pico; the **Try It!** tab runs it |
| `temperature_sensors.krl` | Sample data for the next one |
| `com.example.temperature_sensors_view.krl` | A view over another pico's data |
