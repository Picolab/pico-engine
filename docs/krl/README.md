# KRL Manual

KRL (the Kinetic Rule Language) is the language picos are programmed in. A KRL **ruleset** is a set of rules that react to events and functions that answer queries; installing a ruleset in a pico gives that pico new behavior.

New to KRL? Start with the [Overview](/krl/overview/), then read [Rulesets](/krl/rulesets/) and [Event Expressions](/krl/event-expressions/).
