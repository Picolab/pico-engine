## Scope

### 1. did:peer:4 (new relationships)

| Item | Notes |
|------|--------|
| **Library** | **Done (spike):** TypeScript port of [DIF did-peer-4](https://github.com/decentralized-identity/did-peer-4) in `peerDid4.ts` / `peerDid4Create.ts` — no npm package exists; `@veramo/did-provider-peer` v7 supports numalgo **0/2 only** |

| **Matching** | **Done:** `peerDid4Matches()` in `store.ts` for numalgo 4 short/long forms |
| **Tests** | **Done:** `test/peerDid4.ts` (DIF vector + DIDComm roundtrip); `epic9Matrix.ts` expects peer:4 for new subs; peer:2 regression kept |
