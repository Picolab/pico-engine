## Highlights

1. **PDS installs by default** on the root and every new child. Manifold no longer installs it.
2. **Three long-open issues closed:** developer UI deadlocks ([#493](https://github.com/Picolab/pico-engine/issues/493)), scheduled jobs left behind when a pico is deleted ([#578](https://github.com/Picolab/pico-engine/issues/578)), and module dependency cycles crashing the engine at flush ([#577](https://github.com/Picolab/pico-engine/issues/577)).
3. **CI pinned to Node 20/22.** Node 24 broke krl-parser test timeouts.
4. **Docker from source.** `Dockerfile.local` builds a release image; Helmet's `upgrade-insecure-requests` is off so the UI works over plain HTTP in local Docker.
5. **Community fixes from the quiet years:** `wrangler:picoQuery` logic error (PR #641), a label argument fix (#642), shared `generate_message` for DIDO extensions (PR #649), a clearer error message (PR #654), and dependency updates (PR #652).

## Why it matters

- **A stable floor.** Before adding identity and auth, the engine had to stop deadlocking and leaking schedules. Manifold and sensor-network set 1.4 as their minimum.
- **PDS as a platform service.** Every pico having a personal data store is an assumption later releases (secret settings in 1.10) rely on.

## Upgrade

- Use Node 22 LTS (18+ required; CI tests 20 and 22).
- Manifold requires 1.4+.
